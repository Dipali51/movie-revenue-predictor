# 🎬 Movie Revenue Predictor

## 📌 Project Description

This project is a **Machine Learning based web application** that predicts the revenue of a movie using important features such as:

* 💰 Budget
* 📈 Popularity
* ⏱ Runtime
* ⭐ Average Rating
* 🗳 Vote Count

The application is built using **Python, Machine Learning, and Streamlit**, providing a simple and interactive user interface.

## 🚀 Tech Stack

* 🐍 Python
* 🤖 Machine Learning (Regression Model)
* 🌐 Streamlit (Web Interface)
* 📊 Pandas & NumPy


## ▶️ How to Run the Project
### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Dipali51/movie-revenue-predictor.git
cd movie-revenue-predictor
```

### 2️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 3️⃣ Run the Application

```bash
streamlit run app/app.py
```
